Soft UI untuk Specs

Prinsip dari TypeUI UI Foundations yang relevan untuk kacamata. Gayanya bersih dan lembut: sudut membulat, tanpa bayangan keras, garis tepi tipis hanya jika perlu, satu font (Manrope), dan satu warna aksi (hijau). Setiap layar memakai satu bahasa. Contoh di bawah dalam Bahasa Indonesia.
